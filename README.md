# kyphosis-disease-detection
Code and supporting materials for the 2023 Applied Sciences study on supervised machine learning and deep learning for kyphosis disease detection.

# Kyphosis Disease Detection Using Machine Learning and Deep Learning

## Associated publication

**Title:** Comparative Analysis of Supervised Machine and Deep Learning Algorithms for Kyphosis Disease Detection

**Journal:** Applied Sciences, 2023, 13(8), 5012

**DOI:** https://doi.org/10.3390/app13085012

## Repository contents

- `code/`: Original research code, where available.
- `data/`: Dataset or instructions for obtaining it, subject to applicable licensing.
- `results/`: Available experimental outputs and supporting records.

## Dataset

The study used the Kyphosis dataset obtained from Kaggle:

https://www.kaggle.com/datasets/abbasit/kyphosis-dataset

## Experimental methods

The published study evaluated supervised classification algorithms, including logistic regression, Naive Bayes, random forest, support vector machine, k-nearest neighbors, and deep neural networks, using cross-validation.

Please consult the original publication for the reported experimental methodology and results.
